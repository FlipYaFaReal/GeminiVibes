# GeminiVibes UX Rebrand Design

## Visual Identity
- **Name:** GeminiVibes (was LifePulse)
- **Theme:** Cosmic & mystical, Aurora Borealis color direction
- **Mode:** Dark theme throughout

## Color Palette
- Background: #0B0F1A (deep space)
- Surface: #141B2D (cards, inputs)
- Surface Bright: #1E2940 (hover, selected)
- Primary: #06D6A0 (aurora teal)
- Secondary: #9B5DE5 (aurora purple)
- Accent: #00F5D4 (bright cyan glow)
- Text Primary: #E8ECF4 (soft white)
- Text Secondary: #7B8CA8 (muted)
- Gradient: #9B5DE5 -> #06D6A0 (aurora)
- Danger: #FF6B6B
- Warning: #FFD93D

## Domain Colors (for dark theme)
- Family: #C77DFF (lavender)
- Work: #48BFE3 (sky blue)
- Home: #FFD93D (gold)
- Relationships: #FF6B9D (pink)
- Faith: #06D6A0 (teal)
- Health: #FF6B6B (coral)
- Growth: #9B5DE5 (purple)

## Domain Icons
Ionicons geometric icons, no emojis. Styled with domain colors and glow effects.

## Screens
- Chat: dark bg, gradient header text, teal-bordered AI bubbles, purple user bubbles
- Today: dark bg, radial gradient top, glowing timeline dots, surface cards
- Radar: constellation-style domain nodes with glow intensity = health
- Sign-in: aurora gradient, "Align your universe" tagline, dark Clerk widget
- Tab bar: dark surface, teal active glow
